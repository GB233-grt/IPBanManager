## 1. 软件简介

净域是一个 Windows 本地 HOSTS 封禁工具。它把你要屏蔽的域名写入系统 HOSTS 的“净域托管区域”，让域名解析到 `0.0.0.0` / `127.0.0.1`，从而在**域名解析层**阻止访问。

它能做：

- 添加/编辑/删除封禁规则，按分组管理，一键暂停整组；
- 批量导入域名，自动扩展 `www` / `m` / `api` 等常见子域；
- 每次写 HOSTS 前自动备份，可一键恢复；
- 自定义主题（强调色、明暗、背景图、圆角、卡片透明度）；
- 托盘常驻、关闭到托盘、开机自启。

它不能做：

- 不能按 IP、端口、进程封禁；
- 不修改防火墙、不装驱动、不动网卡；
- 对使用自定义加密 DNS（DoH/DoT）、直连 IP 或系统代理的应用可能无效；
- 不能中断已经建立的连接（例如正在播放的视频需要刷新页面或重开浏览器）。

## 3. 安装与启动

净域是**免安装**的绿色程序：

1. 拿到发布包 `净域-v1.0.0-win-x64.zip`，解压到任意目录，例如 `D:\Tools\净域\`。目录内含 `IPBanManager.exe`、`用户手册.md`、`快速开始.txt`、`版本信息.txt`。
2. 双击 `IPBanManager.exe`。
3. Windows 会弹出 UAC 提权窗口，点击“是”。
4. 若弹出“Windows 已保护你的电脑”（SmartScreen），点击“更多信息”→“仍要运行”（仅首次）。

说明：

- 程序清单要求管理员权限，**取消 UAC 将无法启动**，这是正常现象。
- 程序是**单实例**的：重复双击会提示“净域已经在运行中，请从任务栏托盘打开”。
- 切换版本：直接覆盖 exe 即可，`%APPDATA%\IPBanManager` 中的数据会保留；可用 `版本信息.txt` 中的 SHA256 校验文件完整性。
- 如果只是查看界面，可使用发布包 `净域-v1.0.0-界面预览版.zip`：无需管理员，使用临时数据目录与临时 HOSTS，**不会修改系统文件**。

命令行参数（可选）：

| 参数 | 作用 |
| --- | --- |
| `--minimized` | 启动后直接隐藏到托盘 |
| `--data-dir <目录>` | 使用指定目录作为数据目录（便携/测试用） |

示例：`IPBanManager.exe --data-dir D:\净域数据 --minimized`

## 5. 首次运行

首次启动时：

1. 自动创建数据目录 `%APPDATA%\IPBanManager`，内含 `data.json`、`settings.json`、`theme.json` 及 `backups\`、`logs\`、`assets\` 子目录。
2. 自动创建 5 个内置分组：**学习专注、游戏、视频、广告、自定义**。
3. 规则列表为空，HOSTS 暂不会被修改（没有规则时不生成托管块）。
4. 若数据文件损坏，程序会自动修复并保留损坏文件副本，启动后给出提示。

建议第一次使用前先到“日志与备份”页点击“立即备份”，保留一份当前 HOSTS 快照。

## 6. 添加封禁规则

### 6.1 添加单条/多条规则

1. 打开“规则管理”，点击右上角“添加规则”（首页快捷操作和托盘菜单也可进入）。
2. 在“域名”输入框中填写域名或网址，例如：
   - `bilibili.com`
   - `https://www.bilibili.com/video/BV1xx`
   - `m.weibo.cn`
3. 选择写入方式：
   - **自动（0.0.0.0 + 127.0.0.1）**：默认方式，同时写两条映射；
   - **自定义 IP**：只写一条映射，目标 IP 可填 `0.0.0.0`、`127.0.0.1` 等。
4. 选择分组、填写备注（可选），并决定“启用此规则”。
5. 如需同时封禁常见子域，勾选“同时封禁常见子域”（使用高级设置中的前缀，默认 `www,m,api`）。
6. 对话框底部会实时预览将要写入 HOSTS 的内容；点击保存。

添加成功后：

- 若“自动应用 HOSTS”已开启（默认开启），会立即写入 HOSTS 并刷新 DNS；
- 若已关闭，提示“已保存，等待手动应用 HOSTS”，需要到规则页点击“应用 HOSTS”。

> 域名会统一转为小写并去掉协议、端口和路径。输入 IP 或通配符（如 `*.example.com`）会被拒绝——HOSTS 只能屏蔽域名。

### 6.2 重复域名怎么处理

同一域名重复添加不会产生重复行：已存在的规则会被**更新**（IP 模式、分组、备注、启用状态），HOSTS 中始终只有一条对应记录。

## 7. 批量导入规则

1. 打开“规则管理”，点击“批量导入”。
2. 在文本框中粘贴域名列表，或点击“读取文件”选择 `*.txt`、`*.csv`、`*.list` 文件。
3. 支持格式：
   - 每行一个域名或网址；
   - 以 `#` 开头的行为注释，会被忽略；
   - 支持 `0.0.0.0 example.com` 这类 HOSTS 行（IP 部分会被跳过）；
   - 支持逗号、分号、空白分隔多个域名。
4. 选择目标分组、是否默认启用、是否扩展常见子域；对话框会实时显示“识别 N 个域名 / 扩展后 N 条 / N 个错误”。
5. 点击保存，一次最多导入 2000 条。

导入完成后会提示新增/更新数量；无效行会在对话框中列出原因（如“第 3 行：bad_domain（域名格式不正确）”）。

## 8. 管理规则

在“规则管理”页面：

| 操作 | 方法 |
| --- | --- |
| 搜索 | 顶部搜索框输入域名、备注、分组名或 IP，即时过滤 |
| 按状态筛选 | 状态下拉选择“全部状态 / 仅已启用 / 仅已禁用”（已暂停分组内的规则视为禁用） |
| 按分组筛选 | 分组下拉选择某个分组；分组被暂停时名称后带“（暂停）” |
| 排序 | 最近添加 / 域名 A → Z / 按分组排序 / 状态优先 |
| 启用/禁用单条 | 勾选或取消表格中的复选框 |
| 编辑 | 双击该行，或点击行尾的编辑按钮；编辑模式只能保留一个域名 |
| 删除 | 点击行尾的删除按钮，确认后删除并自动更新 HOSTS |
| 批量启用/禁用 | 工具栏“全部启用 / 全部禁用”，只影响当前筛选结果 |
| 批量删除 | 勾选多行后点击“删除选中” |
| 导出 | 点击“导出选中筛选结果”，导出为制表符分隔的文本（含域名、分组、写入方式、状态、备注，UTF-8 带 BOM） |
| 手动应用 | 点击“应用 HOSTS”，立即写入并刷新 DNS |

表格列说明：域名、目标地址、分组、备注、状态、添加时间、操作。

## 9. 分组与一键暂停

打开“分组管理”：

- 每个分组是一张卡片，显示颜色、名称、规则总数和正在生效的数量，以及一个启用开关。
- **暂停分组**：把卡片上的开关关掉。组内规则在 HOSTS 中会被注释（`# [已禁用]`），但规则自身的“启用”状态**不会改变**；重新打开开关后按原状态恢复写入。
- **查看规则**：点击卡片上的“查看规则”，会跳转到规则页并自动套用该分组筛选。
- **新建分组**：点击右上角“新建分组”，输入名称，自动分配颜色。
- **重命名**：点击卡片上的重命名按钮。
- **删除分组**：自建分组可以删除，组内规则会移动到“自定义”分组，不会丢失；内置分组（学习专注、游戏、视频、广告、自定义）只能改名，不能删除。

> 分组暂停适合“学习/工作时段一键关闭娱乐站点”：不用逐条改规则，恢复时一键还原。

## 11. 主题设置

所有改动**实时预览**，满意后点击右上角“保存主题”持久化。

- **深色模式**：开关切换明暗外观，画布底色会自动跟随。
- **强调色**：点击预设色块，或在“自定义强调色”输入 `#RRGGBB` 后点“应用颜色”。
- **画布底色**：输入 `#RRGGBB` 后点“应用”。
- **背景图片**：“选择”一张本地图片（JPG/PNG/BMP），程序会复制到数据目录的 `assets\`，可用“清除”移除；滑条调整背景图不透明度。
- **圆角强度**：0～24，影响卡片与控件圆角。
- **卡片透明度**：55%～100%，影响卡片和导航背景。
- **导入/导出主题**：导出为 JSON 可分享到其他电脑；导入后立即应用并保存。
- **恢复默认**：恢复默认强调色、背景、圆角和透明度。

> 主题配置保存在 `%APPDATA%\IPBanManager\theme.json`。

## 12. 高级设置

修改后点击右上角“保存设置”；如需立即写 HOSTS，点击“保存并应用 HOSTS”。

| 设置项 | 说明 |
| --- | --- |
| HOSTS 文件路径 | 默认 `C:\Windows\System32\drivers\etc\hosts`；测试或绿色使用时可指向其它文件 |
| 备份目录 | 默认数据目录下的 `backups\`，可改到其它盘 |
| 备份保留数量 | 1～500，默认 50；超出后自动删除最旧的备份 |
| 写入 UTF-8 BOM | 默认关闭；个别老旧工具要求 BOM 时再开启 |
| DNS 刷新方式 | 自动（默认，API + ipconfig）/ 仅 Windows API / 仅 ipconfig /flushdns；“测试刷新 DNS”可立即验证 |
| 屏蔽模板 / 重定向模板 | 用 `{domain}` 表示域名、`{ip}` 表示目标 IP；默认 `0.0.0.0 {domain}` 与 `127.0.0.1 {domain}` |
| 常见子域扩展前缀 | 逗号分隔，默认 `www,m,api` |
| 自动应用 HOSTS | 默认开启；关闭后规则改动只保存，需手动点“应用 HOSTS” |
| 批量导入时默认扩展子域 | 控制批量导入对话框的默认勾选状态 |
| 启用托盘图标 | 托盘常驻开关 |
| 最小化到托盘 | 点最小化时隐藏到托盘 |
| 关闭到托盘 | 点关闭按钮时隐藏到托盘而不退出 |
| 开机自启 | 写入当前用户注册表 `HKCU\...\Run`，命令带 `--minimized` |
| 启动时最小化 | 开机/启动后直接隐藏到托盘 |
| 运行权限 | 显示当前权限；“以管理员身份重启”可一键提权重启；可打开数据目录 |

> 如果修改了 HOSTS 路径，请确认目标目录存在且你有写权限；程序保存时会校验。

## 13. 日志与备份恢复

### 13.1 操作日志

“日志与备份”页左侧是操作记录：

- 每次添加/删除/编辑/启停/应用/刷新 DNS/备份/恢复/改设置都会记录，包含时间、标题、详情和成功/失败标记；
- 顶部可搜索记录，可“清空记录”（只清空界面记录，不删除文件日志）；
- 点击“打开日志目录”可查看按天生成的日志文件 `logs\app-yyyy-MM-dd.log`，排查问题时请提供该文件。

### 13.2 自动备份

- 每次写入 HOSTS 前，程序会把当前 HOSTS 复制为 `hosts_yyyyMMdd_HHmmss_fff.bak`，并生成同名 `.meta.txt` 记录来源、时间和原因。
- 默认保留最近 50 个，可在高级设置调整。

### 13.3 手动备份与恢复

1. 点击“立即备份”随时创建一份快照。
2. 在右侧“HOSTS 备份”列表中选择一个备份（显示文件名、原因、大小、时间）。
3. 点击“恢复选中备份”并确认。
4. 恢复前程序会**先自动备份当前 HOSTS**，恢复后立即刷新 DNS。

注意：备份与恢复只针对 **HOSTS 文件**，不会改动你的规则列表；如果规则和 HOSTS 不一致，恢复后可点击“应用 HOSTS”重新生成托管区域。

## 14. 托盘与开机自启

- **最小化到托盘**：点窗口最小化按钮后，程序隐藏到任务栏托盘，仍在后台运行。
- **关闭到托盘**：点右上角关闭按钮默认不退出，而是隐藏到托盘；如需真正退出，请使用托盘菜单“退出净域”。
- **托盘菜单**：打开主界面、添加封禁规则、全部启用、全部禁用、刷新 DNS 缓存、打开 HOSTS 所在目录、退出净域。
- **开机自启**：高级设置中打开“开机自启”，程序会写入当前用户注册表（`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，值名 `IPBanManager`），不影响其他用户；如同时开启“启动时最小化”，开机后静默驻留托盘。
- 关闭托盘图标后，窗口会恢复显示并退出托盘模式。

## 16. 常见问题

### Q1：启动时没有弹出 UAC，或者提示无法运行？

- 程序清单要求管理员权限。请右键 `IPBanManager.exe` → “以管理员身份运行”。
- 如果 UAC 弹窗被取消，程序会直接退出，这是预期行为。
- 公司/学校电脑可能通过组策略禁止提权，此时无法写入系统 HOSTS，请联系管理员。
- 若提示“净域已经在运行中”，请从任务栏托盘双击图标打开，而不是重复启动。

### Q2：规则已添加，但网站还能打开？

按顺序排查：

1. **规则是否生效**：首页“正在生效”数量是否包含该规则；规则所属分组是否被暂停。
2. **HOSTS 是否已写入**：打开 HOSTS 文件（高级设置可“打开 HOSTS 目录”），确认托管区域里有对应域名；没有就点击“应用 HOSTS”。
3. **DNS 缓存**：点“刷新 DNS”，或手动执行 `ipconfig /flushdns`。
4. **浏览器缓存/连接复用**：关闭所有标签页、重启浏览器；视频/直播类页面可能已建立长连接，需要重开。
5. **加密 DNS（DoH）**：Chrome/Edge 的“安全 DNS”、Windows 11 的“加密 DNS”会绕过 HOSTS。请在浏览器设置中关闭“使用安全 DNS”，或在系统设置中关闭加密 DNS 后重试。
6. **系统代理/应用内置 DNS**：部分代理软件、游戏客户端会自行解析域名，HOSTS 对其无效。
7. **子域名未覆盖**：只封了 `bilibili.com` 时，`www.bilibili.com` 可能需要单独添加（可使用“同时封禁常见子域”）。
8. **验证解析**：执行 `ping bilibili.com`，若显示 `0.0.0.0` 或 `127.0.0.1`，说明 HOSTS 已生效，问题在应用侧缓存或加密 DNS。

### Q3：提示“DNS 刷新失败”怎么办？

- HOSTS 已经保存成功，只是缓存刷新失败，规则通常仍会生效。
- 手动打开命令提示符（管理员）执行：`ipconfig /flushdns`。
- 检查“DNS Client”服务（`Dnscache`）是否运行。
- 到高级设置把刷新方式切换为“仅 Windows API”或“仅 ipconfig /flushdns”后点“测试刷新 DNS”。
- 若所有方式都失败，可重启电脑。

### Q4：HOSTS 编码问题 / 中文乱码？

- 净域默认以 **UTF-8 无 BOM** 写入 HOSTS；读取时可自动识别 UTF-8、UTF-16 与系统 ANSI。
- 注意：如果原 HOSTS 使用系统 ANSI（例如 GBK）保存了中文注释，写回后文件会统一转为 UTF-8。文本内容不会丢失，但按 ANSI 读取的旧工具可能看到乱码。
- 个别老工具要求 UTF-8 BOM，可在高级设置打开“写入 UTF-8 BOM”。
- 如果手动编辑 HOSTS 后出现乱码，建议用支持 UTF-8 的编辑器（如 VS Code、Notepad++）打开并另存为 UTF-8。

### Q5：提示“HOSTS 块外存在同域名记录”？

说明你（或其他软件）在托管区域之外手写了一条同域名的映射。净域不会删除用户行，只会提示冲突——实际生效结果可能不是你期望的。处理方式：

- 打开 HOSTS 文件，手动删除或注释块外那条同域名记录；或
- 把那条记录迁移成净域里的规则，然后点击“应用 HOSTS”。

### Q6：为什么输入 IP 或 `*.example.com` 不能添加？

HOSTS 的语法是“IP + 域名”，只能把域名映射到 IP，不能按 IP 封禁，也不支持通配符。请填写具体域名，或使用“同时封禁常见子域”。

### Q7：规则数据损坏或界面数据异常？

- 程序启动时会自动修复：补齐内置分组、修正非法域名/IP、修正分组归属、移除重复规则、裁剪超量日志。
- 如果 `data.json` 无法解析，原文件会被保留为 `data.json.corrupt-时间戳.json`，程序重置数据并提示。
- 建议从备份中恢复整个数据目录。

### Q8：备份能恢复规则吗？

不能。备份只包含 HOSTS 文件；规则保存在 `data.json`。恢复备份只回滚 HOSTS 内容，之后可再点击“应用 HOSTS”让 HOSTS 与当前规则一致。

### Q9：安全软件拦截写入 HOSTS？

将 `IPBanManager.exe` 加入安全软件白名单，或临时关闭“HOSTS 保护类”功能后重试。程序只改 HOSTS 与 DNS 缓存，不涉及网络层。

### Q10：如何确认程序只改了 HOSTS？

打开 HOSTS 文件查看净域标记区域即可；程序不写注册表（除自启项）、不装服务、不装驱动、不联网。高级设置页面也有安全边界说明。

### Q11：点了右上角关闭按钮，程序为什么还在运行？

这是默认行为：正式版默认开启“关闭到托盘”，点 X 只是把窗口隐藏到托盘，规则仍在生效。要恢复窗口，双击托盘图标或右键选择“打开主界面”；要真正退出，右键托盘图标选择“退出净域”。如果不希望关闭时驻留托盘，可在“高级设置 → 托盘与开机启动”中关闭“关闭到托盘”。

### Q12：界面顶部显示“预览模式”是怎么回事？

说明你运行的是界面预览版（`IPBanManager.Preview.exe`），它不需要管理员权限，HOSTS 指向临时文件，**不会修改系统 HOSTS**。正式使用请运行 `IPBanManager.exe`，启动时会请求管理员权限，界面不会再显示“预览模式”。

## 17. 卸载与彻底清理

1. 打开“高级设置”，关闭“开机自启”和托盘相关选项（或直接删除自启项）。
2. 托盘菜单选择“退出净域”。
3. 在 HOSTS 中删除净域托管区域（从 `# ==== IPBan Manager 托管区域 开始 ====` 到 `# ==== IPBan Manager 托管区域 结束 ====`），或先恢复一份“干净”的备份。
4. 删除程序目录。
5. 如需清除全部数据，删除 `%APPDATA%\IPBanManager` 目录。
6. 执行 `ipconfig /flushdns` 让 HOSTS 修改立即生效。
